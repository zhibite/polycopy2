Source path:
  drpc WSS eth_subscribe(logs) filtered by both V2 exchanges and maker topic
  -> decode OrderFilled -> CLOB token metadata (cached)
  -> data-api-shaped row -> Engine.ingest_rows() (same rules/paper execution)

Reliability:
  - HTTP eth_getLogs catch-up every 15s even while subscribed
  - reconnect + catch-up on WebSocket loss
  - catchup_chunk=100 (drpc free plan rejects ranges over 100 blocks)
  - cursor kv onchain:last_block persisted only after queue drain
  - in-process dedupe (tx_hash, log_index); DB dedupe key identical to data-api
  - automatic HTTP polling fallback with --no-ws / missing websockets
  - drpc primary, publicnode fallback (drpc 30/30 vs publicnode 28/30 in probe)
  - settle/mark run on a separate SQLite connection in a background thread, so
    book walks cannot block signal handling; fills are processed by the main
    loop only

    /root/polycopy-onchain/scripts/compare_sources.py \

    /root/polycopy-onchain/data/paper_f705_onchain.db \
    --verbose --json-out /root/polycopy-onchain/data/compare.json

Compares matched (tx, side, token) signals: latency, chain lead, adverse
slippage vs target fill, and one-sided signals. Pre-start data-api signals are
excluded automatically via the on-chain account creation time.

  changes SELL fraction sizing. The PoC seeded target_positions from the
  data-api DB once. Before replacing the main link, add CTF
  PayoutRedemption / PositionsMerge / PositionSplit logs or a periodic
  positions reconciliation.
